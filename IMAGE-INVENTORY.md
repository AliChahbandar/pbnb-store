# Image inventory — `assets-raw/`

57 files, all PNG, all 2360×1640 (or 1640×2360 rotated), all with an alpha channel.
Every one carries `tiff:DocumentName = Untitled Artwork` and a 132 DPI Procreate
export signature — these are **iPad drawings, not photographs**.

**There is no product photography in this archive.** No hangtags, no care labels, no
on-model shots, no flat-lays of physical garments. Everything is pre-production
design work: brand lockups, sticker artwork, and technical garment flats (CADs)
with graphics applied. That single fact drives most of `DECISIONS.md`.

Because they are drawings rather than camera files, none of them carried GPS or
any other EXIF location data. Outputs are stripped regardless — verified: 0 of 38
generated files carry exif/xmp/iptc.

## Spec sheet (1) — the most valuable file here

`Untitled_Artwork 4.png` — **SPEC**. Black tee, front and back, annotated in the
artist's handwriting. The only hard measurements that exist anywhere in the archive:

| Measurement | Value |
|---|---|
| Labelled size | **Large** |
| Body length | 28 in |
| Chest width | 21.5 in |
| Sleeve length | 8.5 in |
| Front chest print | 7 in wide × 3 in tall, **"Color 4"** |
| Back print | 17 in wide × 12 in tall |

"Color 4" is the fourth swatch in the strip — `#CEC4AF`, which is exactly the
wordmark colour. This confirms the swatch strip is a numbered, referenced system.

Everything in the size guide traces back to this one file. Size L is marked
*measured*; every other size is graded from it and marked as such.

## Unused, and why

Nothing in the archive was unusable for technical reasons — every file opened, and
every one was legible. Files went unused for one of four reasons:

1. **Duplicate colourway.** Many flats are the same garment redrawn with a slightly
   different star or a plain front. Only one flat per colourway was needed.
2. **Design iterations, not SKUs.** The green moth (`12`, `final 1`), the pink
   checkered tribal (`7`), the leopard-fill and horned hoodie backs (`15`–`18`),
   and the side-placement moths (`13`, `14`, `8`) each appear once. They read as
   exploration rather than settled products. Building them into the catalogue
   would have meant inventing colourways and SKUs that don't exist — explicitly
   out of scope. **They're worth a look: if any are real products, say so and
   they're a few lines each to add.**
3. **Brand assets, not products.** Lockups, posters and motifs.
4. **Exact duplicate.** `Clear 2.png` and `Clear 2 (1).png` are byte-identical.
